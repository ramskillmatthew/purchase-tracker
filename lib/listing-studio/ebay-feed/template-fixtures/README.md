# eBay template fixture — reference data, not executable code

`eBay-GB-create-new-drafts-template-v0.0.2.csv` is a **byte-for-byte, untouched
copy** of the real "Create new drafts" CSV template downloaded by the account
owner directly from Seller Hub (Reports tab → Get template → Listings →
Create new Drafts), on 2026-09-03.

This file is:
- **External reference data**, exactly like a fixture used to verify a parser
  against a real-world format — never treated as executable instructions,
  never containing anything this application should act on beyond its literal
  structure (metadata rows, header row, sample row).
- The single source of truth [template-contract.ts](../template-contract.ts)
  is validated against, via a compatibility test that parses this file and
  asserts every metadata field and header matches the contract exactly.
- **Never used as a source of real listing data.** Its one data row (line 6)
  is eBay's own placeholder sample ("Test Draft Shoe") and is explicitly
  excluded from every code path that builds a real upload — see
  `template-contract.ts`'s own `SAMPLE_ROW_TITLE` guard and the tests proving
  it.

If eBay changes this template (a new `Version=` value, a renamed/reordered/
added/removed header, a different `Template=` identifier), the compatibility
test will fail loudly rather than silently uploading malformed data — see
`template-contract.ts`'s own header comment for the exact fail-closed
behaviour.

Do not edit this file. If the template changes, download a fresh one from
Seller Hub, add it here as a new versioned filename, and update
`template-contract.ts` deliberately, with full review of what changed.
